# Rick and Morty

Sleek Rick and Morty fan site built with Next.js, featuring live data from the Rick and Morty API and a custom-designed user interface crafted by me.

---

## 🧠 Overview

This project was developed as part of a personal portfolio to demonstrate:
- Building modern applications using Next.js
- Managing server and client data efficiently
- Creating interactive and animated user interfaces
- Structuring scalable frontend projects

The application is designed to handle dynamic content while maintaining performance and clarity.
